# Çözümler

Örnek çözümler katılımcıların önceden görmemesi için `main`'de değil, ilgili `solution/*` branch'lerindedir:

| Lab | Çözüm dosyası (solution branch'inde) |
|---|---|
| `solution/crash` | `Workshop/Solutions/01-crash.md` |
| `solution/performance` | `Workshop/Solutions/02-performance.md` |
| `solution/memory` | `Workshop/Solutions/03-memory.md` |
| `solution/keychain` | `Workshop/Solutions/04-keychain.md` |
| `solution/concurrency-stale-response` | `Workshop/Solutions/05-concurrency-stale-response.md` |
| `solution/concurrency-data-race` | `Workshop/Solutions/06-concurrency-data-race.md` |
| `solution/concurrency-cancellation` | `Workshop/Solutions/07-concurrency-cancellation.md` |

Kod farkını görmek için: `git diff lab/<ad> solution/<ad>`
